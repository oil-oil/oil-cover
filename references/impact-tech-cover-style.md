# 清爽科技杂志封面风格

这套风格用于小红书 AI 工具、Codex、Claude Code、Agent、Skill、MCP、模型对比和工作流内容。目标是“信息流里足够清楚，同时有苹果式软件产品高级感”。

## 视觉气质

- 像清爽科技杂志、苹果产品展示页、瑞士网格图纸和高级软件产品海报的结合。
- 标题要大而清楚，背景要安静，视觉锚点要少而准。
- 可以使用浅色纸面、冷白空间、淡网格、参考线、编号、小色块和轻微 3D 屏幕。
- 不追求黑底赛博朋克、脏乱科技感、过度霓虹、高饱和渐变和满屏元素。
- 最终图片必须由 `imagegen` 一次性生成完整画面，不能后贴文字、后贴 Logo 或本地合成版式。

## 颜色

- 首选：暖白、冷白、浅灰、深炭黑、鼠尾草绿、香槟米色。
- 点缀：少量信号黄、淡青、暗橄榄绿，用于标签、线条或小编号。
- 避免：大面积黑底、紫蓝霓虹、廉价发光、粉蓝泡泡、泛黄旧报纸、过多棕橙。

## 字体和排版

- 主标题占 35%-50%，使用超粗无衬线、压缩黑体或干净海报体。
- 中英混排要像杂志标题，英文产品名可以很大，中文结论要清楚。
- 副标题只补一个动作、判断或边界，不写解释段落。
- 小标签最多 3 个，每个 2-5 字，做成轻量索引，不做贴纸。
- 留白是核心，不要害怕画面空。

## 视觉锚点

- 真实截图：适合实操、教程、复盘和工作流。用轻微 3D 屏幕、浏览器窗口或卡片方式出现。
- 产品 Logo：适合产品主题和对比主题。用作小识别或局部装饰，不堆巨大 Logo。
- 抽象屏幕：适合没有截图时表达软件工具。只画干净 UI 容器，不伪造具体界面。
- 结构图纸：适合 Skill、MCP、权限、上下文、模型能力。用少量线条、块和编号。

## 常用构图

### 清爽杂志型

- 大标题在上方或左侧，占画面 35%-50%。
- 右下或下方放一个轻量视觉锚点。
- 背景有淡网格、细参考线、编号和一两个小色块。

### 轻 3D 屏幕型

- 屏幕或浏览器窗口占 35%-55%，以轻微透视和柔和阴影出现。
- 屏幕内容可以是抽象 UI 或参考截图的核心区域，不要塞满。
- 标题和屏幕之间保持明显呼吸感。

### 结构图纸型

- 标题放上方，结构图放中下部。
- 使用 3-5 个能力块、箭头、路径线或分层块。
- 像设计稿或工程图纸，不像 PPT 流程图。

### 纯文字强排型

- 只保留大标题、副标题、小编号和少量线条。
- 用字体比例、错位、留白和小色块建立设计感。

## 禁止项

- 不加人物、吉祥物、卡通角色、贴纸和无关 3D 物体。
- 不加水印、hashtag、感叹号、平台小红书风贴纸。
- 不伪造具体产品 UI、聊天记录、终端输出和数据。
- 不把 Logo 拉伸、改形或过度改色。
- 不做成官方产品广告，不暗示合作或背书。
- 不留空白占位等待后期贴字，不使用本地脚本补字或贴图。
- 不做脏乱黑底赛博朋克，不堆满小字和装饰。
