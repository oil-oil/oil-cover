# oil-cover 视觉规范

本规范同时用于脚本模式的分析提示词和 Agent 自主模式。目标是在手机缩略图里读清主题、看到具体证据，并形成有主次的完整画面。

## 先做构图，再选装饰

- 先确定主标题里最值得强调的一个语义短语，以及画面里最能解释它的一项真实证据。
- 为每个画幅分别写出标题、主证据、品牌和可选头像的位置与占比；按最终合成图规划，不能只看无人物底图。
- 标题、证据与头像通过共同轴线、紧凑间距或非关键边缘的轻微重叠形成整体，避免各占一个角落、中间留下没有作用的空洞。
- 留白用于分隔阅读层级，不是固定面积指标。画面空散时先放大、移动或裁取真实主体，不用增加小字、渐变、图标和装饰来填空。
- 规则优先级：用户明确要求 → 事实、原文与资产保真 → 可读性与头像安全 → 构图 → 风格细节。风格细节不能挤小标题或遮挡证据。

## 标题层级与断行

- 用户给定的标题逐字保留，包括型号和标点。只可断行和设计强调，不删改文字。
- 按语义短语断行，不按字符数量均分；不拆开词语、英文产品名或完整语法关系，不把连接词、助动词孤零零留在上一行末尾。
- 从原题中选一个重点短语，字高建议为其余标题的 1.3–1.6 倍。其余文字承担背景或连接作用，仍须在手机端可读。
- 重点字高可从竖版画布高度的 10%–14%、横版的 13%–18% 起步，结合完整标题与可用宽度调整。这是构图参考，不要求每行一样大或铺满同一宽度。
- 提示词须写明完整标题、断行、重点短语、重点与其余文字的字号关系、行距和颜色。不能只写“大字”“有冲击力”。
- 默认现代中文黑体，字重和字距以清楚、舒展为准。通过字号、疏密与局部明暗形成张力，不把所有字都加到最粗。
- 最多使用两种字体；衬线字体、高亮、反白或下划线按需要选一种，不强制每张图出现。
- 品牌使用清楚的官方 Logo 与名称组合。除非用户要求，不追加为第二个标题，也不挤小原题。
- 副标题只在补充必要信息时使用；用户禁用时不加。装饰标签不用于绕过“不要副标题”的要求。

## 真实证据与归因

- 先判断主主题、主产品、承载界面和辅助品牌。外层品牌只对应当前主题或用户显式提供的资产，不从字幕中捞取次要品牌。
- 有字幕时通读，并对照选中帧的时间点及上下文。分清介绍、方案、操作过程、实际结果，不能把幻灯片包装成产品实测。
- 首帧为片头或纯标题时不作为主证据；优先选清晰、相关、能读出具体对象的真实帧。
- 从来源中保留一个主证据和至多两个辅助信息，删除长正文、侧栏历史、路径、通知、时间戳、旧字幕与无关小字。
- 主证据必须在最终图中占有足够可见面积；不能因为保留完整窗口而把重点缩成小配件。被头像盖住的部分不算有效展示面积。
- 可以放大、裁取和重排来源中的信息，但保留来源类型：真实 UI 仍是 UI；幻灯片、示意图仍是解释画面，不能凭空改成产品后台、菜单、仪表盘或操作结果。
- 不新增原材料没有的控件、数字、功能、结果卡片或品牌。“Before/After”等关系必须有同一对象的前后证据。
- 数字、价格和跑分必须可核对；不能可靠重绘时换不含数据表的证据。
- 没有合适证据时说明缺口，不造画面补齐事实。

## 三种画幅

- **3:4**：exact 3:4，默认 960×1280。标题与证据沿纵向衔接，重点证据进入中部，不能只躲在头像后方。长标题按自然语义安排层级，不强行两行。
- **4:3**：exact 4:3，默认 1280×960。B 站首页主封面。根据实际标题安排上下或左右关系，标题与证据都须占有清楚可读的区域，不固定各分一半。
- **16:9**：exact 16:9，默认 1280×720。B 站个人空间伴随版，独立构图。利用横向空间放大主证据，避免仅在左右角各放一个小物件。
- 三版保持标题、归因、字体与配色一致，允许语义断行和布局适配画幅，不把同一构图机械裁切成三版。

## 头像与可见区域

- 头像是否启用来自用户配置。未启用时最终图完全无人物。
- 生图底图必须无人：移除截图中的人脸、头像、摄像头气泡、真人画中画，也不生成替代人物、轮廓或占位卡。
- 启用时由本地代码合成配置中的透明头像，不把头像交给分析或生图模型。
- 固定参数：3:4 宽 55%、top 58%、右侧越界 6%；4:3 宽 38%、top 40%、右侧越界 3%；16:9 宽 32%、top 40%、右侧内收 2%。
- 关键内容安全区：3:4 避开 `x=48%–100%, y=56%–100%`；4:3 避开 `x=60%–100%, y=37%–100%`；16:9 避开 `x=62%–100%, y=37%–100%`。
- 安全区禁止放标题、Logo、必要标签和主证据，但不是一块必须挖空的矩形。背景、物件表面和非关键细节可连续延伸到头像背后；重要信息留在可见侧。
- 本地后处理只允许头像 alpha 合成，不贴字、不贴 Logo、不拼图、不裁切修补。

## 主体与背景

- 默认一个主视觉物件，按内容选择真实窗口、结果、解释图或局部画面，不强制给所有素材添加浏览器框。
- 物件的放大、边缘裁切、轻微透视都服务于可读性和画面联系。正面视角有效，不强制倾斜或越界，不允许后置提示词推翻已选视角。
- 多卡片来源按可读性决定保留数量，不能为了固定张数编造样本。
- 背景使用浅色底、细网格、极轻颗粒及 1–3 个邻近的柔和色相。颜色取自当前素材或用户要求，不继承上一期品牌色。
- 背景明暗围绕标题和主物件安排，色面可以延伸到画面中部，将主体连成整体；不能只在角落放浅色光斑，其余空白无人负责。
- 柔和不等于缺少对比。主标题保持深色，可以对一个关键词使用有限面积的更深品牌色或反白；背景仍不使用霓虹、全光谱彩虹或脏灰重影。
- 少量自然阴影用于区分层次，不堆容器、设备壳、玻璃卡片、厚边或漂浮窗口。
- 主体密度来自放大的真实内容；不添加无来源的模型图标、假 UI、金币或装饰文字填空。

## 产品资产

- 外置 Logo 只使用与当前主产品匹配的可信资产，保留真实形状、比例、颜色与标识特征。无资产则用准确名称，不发明近似 Logo。
- 用户要求品牌明显时，增大可读品牌组合并与标题或证据对齐，不重复品牌名称、不改主标题。
- 素材归档并记录来源，参照 `product-assets.md`。任何历史案例、测试产品、颜色名都不能自动带入当前任务。

## 提示词输出

每张图输出一份自洽的完整提示词，按以下顺序描述，每项只写一次：

1. 画幅、标题原文和事实归因；说明每张参考图的用途。
2. 语义断行、唯一重点短语、字号层级、行距与强调方式。
3. 最终合成构图：标题、可见证据、品牌与头像的百分比区域，以及它们如何连接。
4. 来源中保留与删除的具体内容，保留来源类型；主证据在头像合成后的可见部分。
5. 背景具体颜色、明暗位置，以及按需使用的裁切、透视或阴影。
6. 简短禁止项：改标题、伪造内容、额外人物、无关品牌、水印、遮挡重点。

不要靠重复“干净、精致、克制、大字、留白”代替构图，也不要继续追加与前文冲突的规则。发现规则冲突应修改原规则及代码中的强制补充逻辑。

## 生成后检查

- 逐张查看最终头像合成图及缩略图：能否一眼读出重点；完整标题是否通顺；主证据是否明显；品牌是否清楚；中间是否空散；头像是否遮挡必要信息。
- 同时核对来源：无虚构 UI、数字、品牌或实测结论。脚本成功不代表画面通过验收。
- 每个失败画幅默认最多自动返工一次，保留其他可用版；再次失败说明缺口，不无限重试。用户明确继续时再制作。
- 审美偏好以用户反馈为准；仅因“还能更好看”不自动整套重做。
- 替换前成套保存旧图片与 sidecar。用户选定某版后停止其他候选生成。
